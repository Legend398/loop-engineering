# Provenance

This repository imports the public MIT-licensed foundation snapshot from
[`cobusgreyling/loop-engineering`](https://github.com/cobusgreyling/loop-engineering)
at upstream commit `79b74f0a0188bb11a3fb02af7b6bd02c18377e23`. It is published
from a new Git root and does not preserve the upstream repository's Git ancestry.

The upstream MIT license and attribution remain unchanged in [LICENSE](LICENSE).
Its SHA-256 at the recorded base commit is
`B9B37DCB7BBCB0574D58D66081F7FA521EBD978BE6CDA97142705DE2D8CFA0DE`.

The bounded continuity handoff, map-first codebase discovery, and execution-first
task workflow extensions were implemented independently in the foundation's
existing package and ledger architecture from behavioral specifications. No
private implementation material was used or copied into these extensions.
